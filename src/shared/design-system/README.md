# MentorHub Design System

Единый визуальный контракт. Источник правды для цвета — CSS-переменные
в `src/assets/main.css`. Всё остальное (компоненты, страницы) обязано
использовать только семантические токены.

---

## 1. Правила, которые нельзя нарушать

1. **Никаких хардкод-цветов в компонентах.** Ни `#fff`, ни `bg-white`,
   ни `text-gray-500`, ни `bg-red-50`. Только семантические токены —
   иначе тёмная тема ломается.
2. **Текст поверх brand-заливки — только `text-on-brand`.** Не
   `text-text-primary`: в светлой теме он тёмный и исчезает на фиолетовом.
3. **Не удалять focus-ring.** Глобальный `:focus-visible` задан в
   `main.css`. Если ставите `outline-none`, обязаны дать равноценную
   видимую замену (`focus-visible:ring-2 focus-visible:ring-brand`).
4. **Обе темы.** Любое изменение проверяется и в светлой, и в тёмной.
5. **Тень или граница, но не всё сразу.** Карточка в покое — граница;
   тень появляется при hover/подъёме.

---

## 2. Токены цвета

### Поверхности
| Токен | Назначение |
|---|---|
| `bg-bg` | фон страницы |
| `bg-surface` | карточки, панели, модалки |
| `bg-surface-secondary` | вложенный блок внутри карточки |
| `bg-surface-sunken` | «утопленный» фон: заголовок таблицы, code, пустое состояние |
| `bg-surface-hover` | hover для строк и кликабельных ячеек |

### Текст
| Токен | Назначение |
|---|---|
| `text-text-primary` | заголовки, основной текст |
| `text-text-secondary` | описания, подписи, вторичное |
| `text-text-muted` | плейсхолдеры, отключённое, метаданные |
| `text-on-brand` | текст/иконки поверх `bg-brand` |

### Границы
`border-border-subtle` (разделители внутри карточки) ·
`border-border-default` (контур карточки, инпута) ·
`border-border-strong` (акцентная граница, hover инпута)

> `border-border-brand` оставлен как алиас `border-border-default`
> ради обратной совместимости. В новом коде не использовать.

### Бренд и статусы
`bg-brand` `bg-brand-hover` `bg-brand-active` `bg-brand-soft`
`border-brand-border` `text-brand` · `text-on-brand`

Статусы — тройками: `text-success` / `bg-success-soft` / `border-success-border`.
Так же для `danger`, `warning`, `info`. **Не** использовать
`bg-green-100`, `text-red-600` и т.п.

---

## 3. Типографика

Импорт: `import { typography } from '@/shared/design-system'`

`display` `displaySm` — маркетинг, серифный `font-display`
`h1` `h2` `h3` `h4` — продуктовые заголовки
`subtitle` `body` `bodyLarge` `small` — текст
`label` `caption` `overline` `metric` — вспомогательные

Правила: заголовки — `tracking-tight`; числа в статистике —
`tabular-nums`; длина строки текста — не больше ~75 символов
(`spacing.prose`); серифный `font-display` только для маркетинга,
внутри продукта — Inter.

---

## 4. Форма и ритм

**Радиусы:** `rounded-md` бейдж · `rounded-xl` кнопка/инпут ·
`rounded-2xl` карточка/модалка. Крупнее `2xl` не использовать.

**Отступы:** шкала 4 / 6 / 8 / 12 / 16 / 24. Внутри карточки `p-5`
или `p-6`. Между секциями — `spacing.section`.

**Тени:** `shadow-xs` … `shadow-lg` из `@theme`. Они на базе
`rgba(22,21,29,…)`, не чёрные. Не писать произвольные
`shadow-[0_8px_30px_rgba(0,0,0,0.12)]`.

**Высота контролов:** минимум 44px на мобильном (`min-h-11`),
40px на десктопе. Иконка-кнопка — минимум 40×40.

---

## 5. Движение

Длительность 150–250ms, easing `cubic-bezier(0.16, 1, 0.3, 1)`.
Анимируем `opacity` и `transform`, не `width`/`height`/`top`.
Hover-подъём — максимум `-translate-y-0.5`. Никаких «прыгающих»
карточек и длинных анимаций. `prefers-reduced-motion` уже обработан
глобально.

---

## 6. Состояния — обязательный набор

Каждый экран с данными закрывает **четыре** состояния:

- **loading** — скелетон в форме будущего контента (`App*Skeleton`),
  не спиннер по центру
- **empty** — `AppEmptyState`: что это, почему пусто, и одно
  конкретное действие
- **error** — `AppErrorState`: что случилось + «Повторить»
- **success** — сами данные

Дополнительно: у каждой кнопки, запускающей запрос, — состояние
загрузки; деструктивные действия — через подтверждение.

---

## 7. Доступность

- Контраст текста ≥ 4.5:1, крупного текста и иконок ≥ 3:1 —
  в обеих темах.
- Цвет не единственный носитель смысла: у статуса есть текст/иконка.
- У каждой иконки-кнопки — `aria-label`.
- Модалка: фокус внутрь, `Esc` закрывает, фокус возвращается на триггер.
- Все интерактивные элементы достижимы с клавиатуры и имеют видимый фокус.
- `aria-live` для тостов и инлайновых ошибок формы.

---

## 8. Орнаменты

Кыргызский орнамент — сдержанный акцент, не фон каждой секции.
Уместно: разделитель секции, угол hero, пустое состояние, футер.
Непрозрачность 0.05–0.3, цвет из палитры (`--theme-brand`), никогда
не поверх текста. Компоненты: `KyrgyzDivider`, `KyrgyzCornerAccent`,
`OrnamentDivider`, утилиты `.ornament-divider` / `.ornament-bg`.
